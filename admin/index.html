05

Mang món quà đến người ấy.

Website xuất ra sẽ được đóng gói thành 1 file ZIP tải trực tiếp về máy (bạn có thể chọn nơi lưu), kèm sẵn cấu hình Vercel để triển khai ngay.

Website quà tặng đã sẵn sàng

💾 Tải lại file ZIP (Chọn nơi lưu)Xem bản đã xuất ↗
  1. Giải nén file ZIP hoặc tải trực tiếp lên GitHub repository.
  2. Trong Vercel, chọn Add New → Project và import repository đó.
  3. Vercel sẽ tự nhận diện vercel.json đã chuẩn bị sẵn (Static site không cần build command).
  4. Nhấn Deploy để nhận đường link .vercel.app gửi đến người ấy!

Bản xuất chỉ gồm website người nhận. CMS và các file cấu hình nháp không bị đưa lên Vercel.
